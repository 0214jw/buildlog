# Phase 0 확인 결과

확인일: 2026-10-26 (한국 시간)

상태: **환경·문서 점검 완료, 사용자 결정 대기**. Phase 0의 모든 결정이 끝난 상태는 아니며 Phase 1은 시작하지 않았습니다.

## 1. 수행한 확인

- MVP·PRD·spec·plan과 `.gitignore`, 프로젝트 폴더를 확인했습니다. 프로젝트 내 AGENTS.md는 검색되지 않았습니다.
- Python 3.13.14, pip 26.1.2, Node.js 24.22.1, npm 11.19.1을 확인했습니다.
- Python 내장 SQLite 3.50.4로 메모리 DB 연결과 `select 1` 조회에 성공했습니다. 파일 DB를 만들지 않았습니다.
- `npm`은 PowerShell 스크립트 실행 정책에 막혔으나 `npm.cmd`는 성공했습니다. 시스템 정책 변경은 필요하지 않습니다.
- 포트 8000·5173에 현재 수신 프로세스가 없음을 확인했습니다. 실제 서버 실행은 하지 않았습니다.
- `backend/`, `frontend/`, `database/`는 비어 있습니다. FastAPI는 현재 Python 환경에 설치되어 있지 않습니다.
- `.git` 폴더가 없음을 확인했습니다. Git 초기화나 커밋은 수행하지 않았습니다.
- 공식 배포 메타데이터와 공식 문서로 도구 버전·지원 환경을 조사했습니다. 결과와 출처는 [setup.md](setup.md)에 기록했습니다.

## 3. 기술과 설정 기본안

- React + Vite + JavaScript, FastAPI + Uvicorn을 선택했습니다.
- DB 접근은 SQLAlchemy, 구조 변경은 Alembic, Supabase PostgreSQL 연결은 Psycopg로 정리했습니다.
- 개발 주소는 React `http://localhost:5173`, FastAPI `http://127.0.0.1:8000`을 기본으로 합니다.
- 로컬 개발 DB와 임시 자동 테스트 DB를 분리합니다.
- 환경 변수는 서버의 `APP_ENV`, `DATABASE_URL`, `CORS_ORIGINS`와 프론트의 `VITE_API_BASE_URL`을 기본안으로 정리했습니다.
- 현재 도구의 버전 요구 사항은 설치 환경과 맞습니다. 실제 패키지 설치·의존성 전체 해결·앱 실행은 Phase 1 이후 확인해야 합니다.

세부 버전, 근거 링크, 예정 명령과 환경 변수 설명은 [setup.md](setup.md)에 있습니다.

## 5. 진행 가능 여부

Phase 1의 기본 화면과 API 연결을 시작할 로컬 도구는 준비되어 있습니다. `npm.cmd`를 사용하면 실행 정책 변경 없이 npm을 호출할 수 있습니다.

회원 인증 방식은 사용자 결정이 남아 있으므로 Phase 0 전체를 확정 완료로 표시하지 않습니다. 다만 회원 기능 없이 기본 실행을 만드는 Phase 1 자체에는 해당 결정이 필요하지 않습니다. 사용자 확인 후 Phase 1을 진행할 수 있으며, 인증 결정은 늦어도 Phase 2 전에 완료해야 합니다.

이번 작업에서 변경한 것은 문서뿐입니다. 코드 작성, 패키지 설치, 가상환경·DB·비밀 설정 생성, Supabase 프로젝트 연결, 서버 실행은 수행하지 않았습니다. 기존 README 내용은 변경하지 않았습니다.
